- The work factory ships as its own Node package, `prime-agent-factory` (packages/factory, Node 22.13+), with the same commands, plan, launcher and hosts formats as `prime-agent factory` in the TypeScript build.
- Factory model seats run the `prime-agent` binary directly with the prompt on stdin; `launch --prime-agent-bin`, `launcher.primeAgentBin`, `PRIME_AGENT_FACTORY_AGENT_BIN` or `prime-agent` on PATH choose it, and the resolved path is recorded for every stage and pinned apart from the factory's own runtime.
- Seats own their sessions by default; `launcher.seatHosting: "daemon"` hands them to the agent daemon with `--daemon-hosted`.
- The factory watchdog reads the factory through the package entry and delivers through the agent binary (`--agent-bin`), and recognizes a running `serve` by the package entry.

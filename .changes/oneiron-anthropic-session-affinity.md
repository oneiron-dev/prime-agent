- Anthropic-compatible providers that set `compat.sendSessionAffinityHeaders` in models.json (such as a `cpa-a` proxy) now get sticky routing: each request sends `x-client-request-id` and `x-session-affinity` set to a SHA-256 digest of the session id, never the raw id. Explicit request headers still override them, and turning caching off (`cacheRetention: "none"`) suppresses them.
- Anthropic compat settings that hold only shared keys (`sendSessionAffinityHeaders`, `supportsLongCacheRetention`) now take effect. Before, `supportsLongCacheRetention: false` without `supportsEagerToolInputStreaming` was ignored.

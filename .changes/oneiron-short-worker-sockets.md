- Session worker sockets are named `w-<supervisor key>-<worker id>.sock` (32 bytes, was `worker-…`, 37), so any socket directory up to 70 bytes fits macOS's socket path limit. Leftover old-name sockets of the same daemon are still cleaned up, `prime-agent` daemon discovery never mistakes either name for a daemon, and incident reports attribute both. On macOS an over-long socket path now fails with the limit named instead of the kernel's `SUN_LEN` error.

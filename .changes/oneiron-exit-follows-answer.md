- Print and json runs (`-p`, `--mode json`) now exit right after their answer instead of lingering for seconds (up to the length of a fresh kernel setup). On a fresh home the Python kernel environment is set up before the first turn rather than after the answer; the kernel itself still starts in the background and is stopped when the run ends, along with any `uv` or Python setup process it started. `--daemon-hosted` runs wait at most 300 ms for the daemon to acknowledge the detach. `--verbose` prints timestamped exit phases and each kernel setup step to stderr.

- Oneiron build: the `python_repl` cell time limit (upstream #3829, ported) also arms in daemonless print-mode sessions (`prime-agent -p`), so a spinning cell can no longer hold a leg's process for hours. The default limit is 30 minutes (upstream: 60 s), the largest per-call `timeout` is 1800 s, and `PRIME_AGENT_REPL_CELL_TIMEOUT_S` (whole seconds, `0` = no limit) sets the default over the `pythonCellTimeoutMs` setting. A timed-out cell that ignores the interrupt for 10 s is force-aborted and its kernel restarted; the tool error says the kernel state is lost.

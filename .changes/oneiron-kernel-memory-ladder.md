- Each Python kernel, with the processes it starts, now has a memory ceiling (16 GB by default). Near 60% the next cell result warns and names the largest variables; past the limit Prime Agent first stops a child process that holds most of the memory, then stops the running cell and deletes the largest variables, and ends the kernel only if memory stays above the limit for 10 seconds or passes 1.5 times the limit. Every step is explained in the next cell result, and files on disk are never touched.
- When the machine itself is nearly out of memory, the largest kernel this session owns is stopped first.
- Set the ceiling with the `kernelMemoryLimitGb` setting or `PRIME_AGENT_KERNEL_MEMORY_LIMIT_GB` (`0` turns it off), and the machine-wide stop with `kernelMemoryBackstop` or `PRIME_AGENT_KERNEL_MEMORY_BACKSTOP`. The ipython tool description and the system prompt state the ceiling while it is on.

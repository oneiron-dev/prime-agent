- `--no-tools` (`-nt`), `--no-builtin-tools` (`-nbt`) and `--tools <list>` (`-t`) now take effect in print, json, daemon-hosted, interactive, RPC and ACP sessions. An explicit `--tools` list (even `--tools ""`) wins over both disable flags in any order; names that match no tool are ignored. A session with no active tools (`--no-tools`, `--tools ""`, or a list naming no available tool) sends no tool definitions. Whenever `ipython` is not active the session never starts a Python kernel (no prewarm, no snapshot revival) and uses the same short system prompt as the TypeScript build, with `--append-system-prompt` text and `APPEND_SYSTEM.md` appended to it. `prime-agent prompt` accepts the same flags.
- A daemon-hosted or interactive session asks the daemon for its tool selection: a daemon too old to honor it is refused with a clear error instead of running every tool, and `--daemon-hosted -c`/`--resume` refuses to reuse a running session that was started with different tool flags.
- A daemon-hosted or interactive session keeps its tool flags when the daemon idles it out and wakes it again, when it moves onto a new session, and in the subagents it spawns.
